# Checklist de entrega

- [ ] Escopo e critérios do pedido atendidos; comportamento demonstrativo explicitado.
- [ ] Consultados contexto e design system aplicáveis; documentação atualizada sem fontes conflitantes.
- [ ] `npm run build` concluído.
- [ ] Suítes afetadas executadas; alterações compartilhadas verificadas com `npm test`.
- [ ] Interface verificada em claro/escuro, desktop, tablet e celular.
- [ ] Teclado, foco, estados de erro, diálogos e seletores relevantes conferidos.
- [ ] Sem overflow horizontal; conteúdo acessível em altura reduzida.
- [ ] Evidências e falhas reais relatadas; não afirmar sucesso de testes não executados.
- [ ] Nenhuma credencial, dado privado ou artefato gerado incluído inadvertidamente.
